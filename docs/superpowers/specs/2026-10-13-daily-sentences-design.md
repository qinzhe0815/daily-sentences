# Daily Sentences 本地 MVP 设计

需求基线为根目录 PRD.md。直接执行用户已授权的完整首版，不发布公网服务。

采用 Node.js 24 原生 HTTP 服务、SQLite 事务持久化和浏览器 ES modules。无需 npm 生产依赖。SQLite 保存一个带版本号的本地学习聚合，服务内所有修改通过同步事务完成，AI 返回时按稳定对象 ID 重新读取并更新，防止跨对话串写。客户端只接收公开视图，隐藏未提交题目的参考答案和未完成诊断的点评。

服务端模块：model 负责数据约束、备份关系校验和调难；store 负责事务与恢复；ai 负责兼容 Chat Completions 的服务适配和结构验证；service 负责生成、诊断、作答和追问的持久化生命周期；http 负责同源本地 API 与静态资源。AI 配置单独保存，不进入学习备份。没有服务配置时保留可操作的设置与明确错误。

界面采用深色导航、米白练习画布和绿色操作色，支持桌面侧栏与移动抽屉。全局界面三语言，题目按快照显示实际语言。每次提交前保存答案，失败重试同一尝试；修改和复习创建新尝试。诊断默认为五道主动翻译，完成前隐藏反馈，结束后由用户决定更新基准。语音使用浏览器 SpeechRecognition，支持 zh-CN/en-US/fr-FR；不支持时明确提示使用支持的浏览器与文字降级，不宣称所有浏览器均支持。

验证分成模型/存储测试、使用本地协议测试服务的 HTTP 集成测试、真实浏览器流程检查。协议测试服务只在测试内存在，不能当作 AI 内容质量证据。真实在线服务、三语言语音与人工点评质量单独记录尚待实测的范围。
