## 模型与内容质量

实际安装官方 Ollama 运行时及 Qwen 3.5 4B GGUF（`qwen3.5:4b-q4_K_M`）；保留可选择较小模型和在线兼容模型的配置。实际请求使用 Ollama 原生接口及 JSON Schema，不使用演示题替代失败结果。

`docs/validation/local-model-smoke.json` 保存六种方向的合成抽样原句、模型参考、点评和耗时。六方向均成功出题及点评（每方向约 10–16 秒），结构和讲解语言校验通过。它检查结构和语言规则，并展示内容；以模型自己生成的参考作答只能作为协议冒烟测试，不能证明合理变体、否定或语义反转被可靠评分。

小模型存在讲解语言错误、误译及不合理建议的风险。未完成三种目标语言的独立人工核查、30 题难度观察及 7 天使用观察，因此不宣称教学准确率、难度匹配率或学习效果已获验证。用户可在设置切换到更强的本地或在线模型。

## 已知边界

- 自动下载安装器目前支持 macOS；其他系统需自行安装 Ollama。
- 首次模型下载需要网络；模型就绪后文字练习可离线，浏览器语音不保证离线。
- 本机地址不供手机或局域网直接访问；未开放无认证的公网服务。
- 在线支持 Chat Completions 兼容协议；原生 Anthropic / Gemini 需兼容网关。
- 麦克风、实际手机及三语言人工教学核查属于尚未完成的实机／使用验证。

模型接入排查记录：自动 `4b` 标签在本机选到 MLX safetensors，实测未执行传入的语言 schema，出现讲解语言错误；改用明确 GGUF 标签后六方向复测通过。安装器默认固定此标签。知识点可能包含译文短语，现仅在成功点评后展示，诊断和复习首次作答时隐藏。

固定评分样例见 `docs/validation/grading-cases.json`，覆盖正确改写、英式词汇、法语礼貌请求、否定反转、错误时态、中文自然译法。首次抽样暴露出模型把严重误译标为无效作答的问题，现增加提示与矛盾校验，禁止发布这类无分点评。仍观察到讲解术语不严谨，例如把法语条件式现在时误称为“条件式近过去时”；完整独立人工质量核查尚未完成，不能把协议成功等同教学可靠。

最终实机文字流程：正式服务创建中文→英语对话，千问生成原句并对手动输入译文给出完整点评；重启应用后，同一题目、作答和 99 分点评仍保留，未重新出题。固定样例最终结果：正确改写 100、地区变体 100、法语礼貌表达 100、中文自然译法 100、否定反转 58、错误时态 54。以上是少量样例结果，不代表准确率。应用预览截图见 `docs/validation/practice.jpg`。
