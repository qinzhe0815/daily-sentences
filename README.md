# Daily Sentences · 译日

本地单用户的中／英／法翻译练习应用。依据 [PRD](PRD.md) 实现，支持六种翻译方向、五题表达诊断、本地分级语料优先出题、独立对话、文字与语音草稿、多版本点评、追问、自适应难度、收藏复习及备份恢复。

服务端与客户端的启动步骤、AI 配置、日常操作和常见问题，见 [使用文档](docs/USAGE.md)。

## 启动

需要 **Node.js 24.14 或更新的 24.x 版本**。应用无 npm 生产依赖，无需 `npm install`。

```sh
cd daily-sentences
npm start
```

这条命令启动服务端，并同时提供 `public/` 中的客户端文件。客户端无需单独运行命令，在浏览器打开 <http://127.0.0.1:3210> 即可；不要直接双击 HTML 文件或另开静态服务器。

退出终端服务时使用 Ctrl+C。`npm run dev` 在服务端源码变化后自动重启；前端文件修改后刷新浏览器。默认仅监听本机，不支持手机通过局域网直接连接电脑；手机布局可用浏览器窄屏或设备模拟检查。公网部署、账号与云同步不在首版范围。

## 本地千问

设置页默认选择 Ollama 本地千问 Qwen 3.5 4B，无需 API 密钥。点击“下载并配置本地千问”，或运行：

```sh
npm run setup:local
```

macOS 自动安装将官方 Ollama 运行时及模型下载至 `data/`，不会安装系统服务。下载运行时先验证固定 SHA-256，再解压；下载进度来自实际字节数。默认模型与运行时共占用约 3.6 GB，建议至少预留 5 GB。初次下载需要网络及足够磁盘空间，完成后文字练习可离线运行。已安装的 Ollama 也可复用。自动安装当前支持 macOS；其他系统请从 [Ollama 官网](https://ollama.com/download) 安装并执行：

```sh
ollama pull qwen3.5:4b-q4_K_M
ollama serve
```

本地接口为 Ollama 原生 `/api/chat`，使用 JSON Schema 约束输出并关闭思考模式。已有自己的 Ollama 时，模型由原服务的数据目录管理；项目自行启动的运行时使用 `data/models/`。应用只停止自己启动的服务。

小模型可能产生误译、不合理润色或误判；结构验证无法证明教学正确。建议将重要问题与更强模型或人工核查结果对照。默认固定使用 GGUF 标签 `qwen3.5:4b-q4_K_M`，避免自动选择到结构约束行为不同的 MLX 变体。设置可填写其他已安装模型名，不限制为默认型号。实测样例保存在 `docs/validation/`。

## 在线 AI

设置 → AI 服务 → 在线模型，填写 **Base URL、模型名与密钥**。支持提供 Chat Completions 兼容接口及 JSON 输出模式的服务，例如千问 DashScope、DeepSeek、OpenAI 和兼容网关。Base URL 应包含 API 前缀，应用自动追加 `/chat/completions`。

| 服务                       | Base URL                                            | 模型名示例                                 |
| -------------------------- | --------------------------------------------------- | ------------------------------------------ |
| 千问 DashScope（中国内地） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus`                                |
| DeepSeek                   | `https://api.deepseek.com/v1`                       | `deepseek-chat`                            |
| OpenAI                     | `https://api.openai.com/v1`                         | 填写账户可用且支持 Chat Completions 的模型 |
| 其他兼容服务               | 供应商提供的兼容 Base URL                           | 供应商模型 ID                              |

模型名和可用区域以服务商账户为准。原生 Anthropic/Gemini 协议需兼容网关，当前没有专用适配器。未提供在线凭证，因此本交付只验证兼容协议，未验证各供应商真实账户请求。

密钥保存在 `data/ai-config.json`，文件权限限制为当前用户；不会返回浏览器或进入学习备份。切换本地／在线会保留既有在线配置；切换在线地址时不会将旧密钥自动带到新服务。也可复制 `.env.example` 为 `.env` 配置；已保存的设置页配置优先于环境变量。

## 使用流程

1. 每次新建对话都选择出题语言、目标语言和角色，并询问“简短诊断”或“跳过，自选水平”，默认进行五道主动翻译诊断。已有该目标语言档案也会显示两个选项。
   选择跳过时，可沿用预填的档案水平或手动调整（无档案默认 L2）；所选水平用于当前新对话，不自动覆盖已有档案。下次新建仍默认诊断；恢复已有对话继续原进度。
2. 诊断结束后可调整估计水平，并选择是否更新该目标语言的全局基准。
3. 输入译文并提交，查看整体判断、错误／可选润色、参考表达与加权评分。
4. “修改答案”创建新版本；“追问”独立于翻译作答，关联选定的点评。
5. 只有主动点击“下一题”才继续出题。角色、语言和场景变更从下一题生效，当前题按原快照点评。
6. 收藏题目或某次点评；重新练习会先隐藏旧答案，提交后展示历次对比。

只有正常新题有效的首次作答参与调难。五题平均 ≥85 且最低 ≥70 升一级，平均 <60 降一级；修改、复习、诊断、跳过、无效作答和失败不参与。固定模式不自动变级或跨级浮动。

## 本地分级语料库

内置 **300 道中／英／法翻译任务**，来自 Tatoeba 官方 API 的 150 个直连句对，覆盖六个方向与 L1–L5。按语义家族隔离练习、诊断和维护评估；后者不参与出题。各分区、角色和场景的实际数量见 [发布报告](corpus/REPORT.md)。

应用优先从本地库取符合方向、等级、角色及场景的未见任务；指定场景无覆盖或库用尽时由 AI 补充。题目卡标明来源，普通题点评后／诊断完成后可查看原文、译文双方署名和许可。自定义场景只做明确别名精确匹配，无法匹配时回退 AI。

**这是实验语料：已完成自动筛选与 AI 编选；2026-10-15 按用户要求，300 道任务全部视为人工检查通过。** 账本分别统计用户要求视为通过与独立逐题审核记录，不补造审核者资质或逐题检查证据；真实学习者难度校准仍待完成。 来源可追溯不代表官方认证。取题本身不需模型；点评、追问、诊断总结和补充出题仍需要本地或在线 AI。

[编写与维护规范](docs/CORPUS_GUIDE.md) · [人工审核与校准办法](docs/CORPUS_HUMAN_REVIEW.md) · [运行库](corpus/tasks.json) · [署名与许可](corpus/ATTRIBUTION.md)。上游文本各自适用 CC BY 2.0 FR 或 CC0 1.0，数据许可独立于项目代码。

```sh
npm run corpus:collect # 官方 API 采集，已缓存响应不重复下载
npm run corpus:build   # 从快照与编选离线重建
npm run corpus:check   # 检查构建产物一致性
```

## 语音支持

使用浏览器 `SpeechRecognition`／`webkitSpeechRecognition`，设置识别语言 `zh-CN`、`en-US`、`fr-FR`。支持能力取决于浏览器版本、操作系统、麦克风授权和识别服务。建议使用具备该 API 的 Chrome 或 Safari；本机 localhost 可作为安全上下文。内嵌浏览器与 Firefox 可能不支持。

录音最长 60 秒，支持停止、取消、追加转写和撤销追加；结果始终是可编辑草稿，不自动提交。不保存原始录音，不评价发音；浏览器识别服务可能把音频发送到浏览器供应商的服务。当前没有服务端语音替代方案，明确限定支持环境。自动化测试验证了三语言参数、降级与会话隔离，真实麦克风和三语言听写仍需在用户浏览器实测。

## 数据与恢复

- `data/learning.sqlite`：正式学习数据、题目快照、作答版本、点评、追问、收藏、诊断和草稿。
- `data/ai-config.json`：服务端 AI 配置及密钥，独立于学习记录。
- `corpus/`：随源码分发的语料、官方快照、编选和署名；不依赖个人 `data/`。学习备份保留已出题快照，不复制整个语料库。
- `data/models/`、`data/runtime/`：本地模型和运行时，不属于学习备份。
- 设置页可导出完整 JSON 学习备份。导入先验证结构与关联、显示数量，再由用户明确确认替换；替换前在 `data/before-import-*.json` 自动保存旧数据。
- 服务中断的请求在重启时标记中断；答案保留，可重试同一尝试。自动保存失败会明确显示未保存，浏览器临时草稿辅助恢复，不替代服务端正式记录。
- AI 请求仅携带当前任务所需内容。不会上传全部学习历史或使用外部分析服务。

学习备份包含用户作答和文字内容，请按个人数据保管。复制整个 `data/` 会同时复制密钥；分享学习记录应使用设置页导出。

## 开发与验证

```sh
npm test
npm run check
# 已启动本地千问后：实际模型六方向出题／点评抽样
node scripts/verify-local.mjs
node scripts/verify-grading.mjs
# 真实本地语料六方向取题／点评（独立临时学习库）
node scripts/verify-corpus-local.mjs
# 独立临时数据的可视化 QA（固定协议数据，不是 AI 质量证明）
node tests/browser-server.mjs
```

`docs/ACCEPTANCE.md` 记录自动化、浏览器和内容质量的验证边界。测试监听本机端口，在限制网络监听的沙箱内需授权本地监听。

## 结构

```text
server/model.mjs      数据校验、公开视图、难度规则
server/store.mjs      SQLite 事务、恢复、备份
server/prompts.mjs    分任务提示与 JSON Schema
server/ai.mjs         本地 Ollama / 在线兼容服务适配
server/runtime.mjs    可选的本地运行时安装与模型下载
server/service.mjs    学习流程与对象级请求锁
server/corpus.mjs     本地语料匹配、方向／分区／全局家族去重
corpus/               官方快照、编选、300 道任务及覆盖／署名报告
scripts/*corpus*      采集、筛选和离线构建
server/http.mjs       同源本地 API 与静态资源
public/               三语言响应式界面及语音适配
```

Node 24 的内置 SQLite 会打印实验性功能提示；这不是测试失败。数据库版本与备份格式均为 1。部署到多用户或公网前需要独立实现身份认证、隔离、配额、传输保护及同步，不能直接开放当前服务。
